# Завдання для теми "Позиційна система числення. Класи та розряди"

## Створені завдання

У папці `tasks` створено 10 освітніх завдань для закріплення знань з позиційної системи числення, об'єднаних у 2 файли:

### Файл: input-write-numbers.json (6 завдань InputTask)

1. **natural-numbers-write-001** - Easy (100 XP)
   - Запис числа "триста сорок п'ять тисяч вісімсот дев'ять" цифрами
   - Відповідь: 345809

2. **natural-numbers-write-002** - Easy (100 XP)
   - Запис числа "сім тисяч двісті тридцять чотири" цифрами
   - Відповідь: 7234

3. **natural-numbers-write-003** - Medium (150 XP)
   - Запис числа "п'ять мільйонів сорок дві тисячі сто три" цифрами
   - Відповідь: 5042103

4. **natural-numbers-write-004** - Medium (150 XP)
   - Запис числа "двісті тисяч триста сорок п'ять" цифрами
   - Відповідь: 200345

5. **natural-numbers-write-005** - Hard (200 XP)
   - Запис числа "дванадцять мільйонів триста сорок тисяч п'ятсот шість" цифрами
   - Відповідь: 12340506

6. **natural-numbers-write-006** - Medium (150 XP)
   - Запис числа "шістсот тисяч сімдесят вісім" цифрами
   - Відповідь: 600078

### Файл: mcq-all.json (4 завдання MultipleChoiceTask)

1. **natural-numbers-compose-001** - Medium (150 XP)
   - Складання числа з розрядних доданків
   - Питання: Яке число містить 3 сотні тисяч, 7 десятків тисяч, 5 тисяч, 2 сотні, 4 десятки та 8 одиниць?
   - Правильна відповідь: 375248

2. **natural-numbers-rank-001** - Easy (100 XP)
   - Визначення розряду цифри в числі
   - Питання: У числі 405723 який розряд займає цифра 5?
   - Правильна відповідь: Одиниці тисяч

3. **natural-numbers-identify-001** - Easy (100 XP)
   - Перевірка правильності запису числа
   - Питання: Яке число записано правильно: дев'ять мільйонів сімсот тисяч двісті п'ятдесят?
   - Правильна відповідь: 9700250

4. **natural-numbers-class-001** - Medium (150 XP)
   - Визначення класу цифр в числі
   - Питання: У числі 7205439 який клас містить цифри 7, 2, 0?
   - Правильна відповідь: Клас мільйонів

## Структура завдань

Всі завдання створені відповідно до специфікацій системи:

- Використовують стандартні типи: `input` та `multiple-choice`
- Мають унікальні ID
- Включають різні рівні складності (easy, medium, hard)
- Містять відповідну кількість XP за правильну відповідь
- Для MultipleChoiceTask додаються пояснювальні коментарі до неправильних варіантів

## Особливості реалізації

1. **Організація файлів**: Подібні завдання об'єднані в масиви для кращої структури
2. **Прогресивна складність**: Від простих чисел до складних багатозначних
3. **Різноманітність**: Поєднання завдань на запис чисел та теоретичних питань
4. **Освітня цінність**: Кожне завдання спрямоване на конкретний аспект теми

## Інтеграція з системою

Завдання автоматично завантажуються системою через функцію `loadTasks` з директорії `content/math/natural_numbers_system/tasks` і інтегруються з:

- Системою перевірки відповідей
- Системою нарахування XP
- Системою відстеження прогресу
- Компонентами візуалізації завдань (InputTask, MultipleChoiceTask)
