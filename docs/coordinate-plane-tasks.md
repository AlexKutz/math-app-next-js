# Coordinate Plane Task Type

## Опис

Новий тип завдань `coordinate-plane` дозволяє створювати інтерактивні вправи для розстановки точок на координатній площині. Користувачі можуть клікати на сітку координат, щоб поставити або видалити точки.

## Особливості

- 🎯 Інтерактивна координатна площина з сіткою
- 📍 Можливість розміщувати декілька точок
- ✅ Автоматична перевірка правильності координат
- 🎨 Темна/світла тема
- 🔄 Можливість видаляти точки (повторний клік)
- 📊 Відображення правильних відповідей при помилці

## Структура JSON

```json
{
  "id": "unique-task-id",
  "type": "coordinate-plane",
  "difficulty": "easy|medium|hard",
  "baseXP": 1500,
  "question": "Текст завдання",
  "correctPoints": [
    { "x": -3, "y": 8 },
    { "x": 5, "y": -4 }
  ],
  "gridSize": {
    "minX": -10,
    "maxX": 10,
    "minY": -10,
    "maxY": 10
  }
}
```

## Параметри

### Обов'язкові поля:

- `id` (string) - унікальний ідентифікатор завдання
- `type` (string) - тип завдання, має бути `"coordinate-plane"`
- `question` (string) - текст питання
- `correctPoints` (array) - масив правильних точок з координатами `{x, y}`

### Опціональні поля:

- `difficulty` (string) - складність: "easy", "medium", "hard" (за замовчуванням "easy")
- `baseXP` (number) - базова кількість XP за завдання (за замовчуванням 1000)
- `description` (string) - додатковий опис завдання
- `gridSize` (object) - розмір координатної площини (за замовчуванням від -10 до 10)
  - `minX`, `maxX` - мінімальне та максимальне значення по осі X
  - `minY`, `maxY` - мінімальне та максимальне значення по осі Y

## Приклади завдань

### 1. Проста точка

```json
{
  "id": "coord-plane-001",
  "type": "coordinate-plane",
  "difficulty": "easy",
  "baseXP": 1500,
  "question": "Постав точку A з координатами (-3; 8) на координатній площині",
  "correctPoints": [{ "x": -3, "y": 8 }]

```

### 2. Дві точки

```json
{
```

## Як створити нові завдання

1. Створіть JSON файл у папці `tasks` вашої теми (наприклад, `001-coordinate.json`)
2. Додайте масив об'єктів завдань у форматі, описаному вище
3. Завдання автоматично завантажаться при відкритті теми

## Технічні деталі

### Компоненти:

- `CoordinatePlaneTask.tsx` - основний компонент завдання
- `TCoordinatePlaneTask` - TypeScript тип у `types/task.ts`

### Функції перевірки:

- Перевірка відбувається в `components/tasks/utils.ts` у функції `checkTaskAnswer`
- Порівнюються координати всіх поставлених точок з правильними відповідями
- Порядок точок не має значення

### Зберігання відповідей:

- Відповіді серіалізуються у JSON формат перед відправкою на сервер
- При завантаженні десеріалізуються назад у масив координат
