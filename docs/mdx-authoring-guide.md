## Структура MDX-файлу

Кожен MDX-файл складається з двох частин:

1. **Frontmatter** — метадані у форматі YAML (між `---`)
2. **Контент** — власне зміст статті

```mdx
---
title: 'Назва уроку'
description: 'Короткий опис'
difficulty: 'easy'
math: true
---

# Заголовок статті

Текст статті...
```

---

## Frontmatter (метадані)

| Поле          | Тип     | Опис                           | Можливі значення               |
| ------------- | ------- | ------------------------------ | ------------------------------ |
| `title`       | string  | Назва уроку                    | Будь-який текст                |
| `description` | string  | Короткий опис                  | Будь-який текст                |
| `difficulty`  | string  | Рівень складності              | `'easy'`, `'medium'`, `'hard'` |
| `math`        | boolean | Увімкнення математичних формул | `true`, `false`                |

### Приклад frontmatter:

```mdx
---
title: 'Позиційна система числення. Класи та розряди'
description: 'Позиційна система числення. Класи та розряди'
difficulty: 'easy'
math: true
---
```

## Заголовки

Використовуйте `#` для створення заголовків різних рівнів.

```mdx
# Заголовок H1 (головний)

## Заголовок H2 (розділ)

### Заголовок H3 (підрозділ)

#### Заголовок H4 (пункт)
```

### Рекомендації:

- **H1** — один на всю статтю (головна назва)
- **H2** — основні розділи (з'являються в змісті)
- **H3-H4** — підрозділи (з'являються в змісті)

## Текст та форматування

### Основний текст

Просто пишіть текст у форматі Markdown:

```mdx
Це звичайний абзац тексту.

Це інший абзац. Абзаци розділяються порожнім рядком.
```

### Жирний текст

```mdx
**Цей текст буде жирним**

**Також жирний текст**
```

**Результат:** **Цей текст буде жирним**

### Курсив

```mdx
_Цей текст буде курсивом_

_Також курсив_
```

**Результат:** _Цей текст буде курсивом_

### Жирний + курсив

```mdx
**_Жирний курсив_**

**_Жирний курсив_**
```

**Результат:** **_Жирний курсив_**

### Закреслений текст

```mdx
~~Цей текст закреслено~~
```

**Результат:** ~~Цей текст закреслено~~

## Зображення

### Базовий синтаксис (Markdown)

```mdx
![Альтернативний текст](https://example.com/image.jpg)
```

### Розширений синтаксис з контролем розміру (рекомендований)

Використовуйте компонент `<Image>` (з великої літери) для повного контролю:

```mdx
<Image
  src='https://i.imgur.com/abc123.png'
  alt='Опис зображення'
  width='400'
  height='300'
  align='center'
/>
```

> **Важливо:** Використовуйте `<Image>` з **великої літери**, не `<img>`. Тільки компонент `<Image>` підтримує атрибути розміру та вирівнювання.

> **Технічна деталь:** Компонент `<Image>` використовує `next/image` під капотом, що забезпечує автоматичну оптимізацію (lazy loading, WebP/AVIF конвертацію, responsive srcset).

### Підтримувані хостинги зображень

- **Imgur** — `https://i.imgur.com/...`
- **imgBB** — `https://i.ibb.co/...`

### Атрибути компонента Image

| Атрибут  | Значення                  | За замовч. | Опис                                                |
| -------- | ------------------------- | ---------- | --------------------------------------------------- |
| `src`    | URL зображення            | —          | **Обов'язковий.** Посилання на зображення           |
| `alt`    | Текст                     | `''`       | Альтернативний текст для доступності                |
| `width`  | Рядок (px), напр. `"500"` | `800`      | Ширина зображення в пікселях                        |
| `height` | Рядок (px), напр. `"300"` | `600`      | Висота зображення в пікселях                        |
| `align`  | `left`, `center`, `right` | `center`   | Горизонтальне вирівнювання                          |
| `wrap`   | `true`, `false`           | `false`    | Текст обтікає зображення                            |
| `shadow` | `true`, `false`           | `true`     | Тінь навколо зображення (вимкніть для прозорих PNG) |

> **Важливо:** Для атрибутів `width` та `height` використовуйте рядковий синтаксис `width="500"`, а не `width={500}`.

### Приклади використання зображень

#### 1. Центроване зображення (за замовчуванням)

```mdx
<Image
  src='https://i.imgur.com/abc123.png'
  alt='Ілюстрація розрядів'
  width='512'
  height='384'
/>
```

#### 2. Маленьке зображення зліва

```mdx
<Image
  src='https://i.ibb.co/abc123/icon.png'
  alt='Іконка'
  width='128'
  height='128'
  align='left'
/>
```

#### 3. Зображення з обтіканням тексту (справа)

```mdx
<Image
  src='https://i.imgur.com/diagram.png'
  alt='Діаграма'
  width='256'
  height='192'
  align='right'
  wrap='true'
/>

Текст буде обтікати зображення справа. Це корисно для ілюстрацій у навчальних статтях.
```

#### 4. Повна ширина (за замовчуванням)

```mdx
<Image src='https://i.imgur.com/wide.jpg' alt='Широке зображення' />
```

#### 5. Зображення без тіні (для прозорих PNG)

```mdx
<Image
  src='https://i.ibb.co/abc123/transparent.png'
  alt='Іконка'
  width='200'
  height='200'
  shadow='false'
/>
```

## Математичні формули

Для використання математичних формул увімкніть `math: true` у frontmatter.

### Вбудовані формули (inline)

Використовуйте одиничні долари `$...$`:

```mdx
Формула площі кола: $S = \pi r^2$

Квадратний корінь: $\sqrt{x^2 + y^2}$
```

**Результат:** Формула площі кола: $S = \pi r^2$

### Блокові формули (display)

Використовуйте подвійні долари `$$...$$`:

```mdx
$$
E = mc^2
$$

$$
\int_{a}^{b} f(x) \, dx = F(b) - F(a)
$$
```

**Результат:**

$$
E = mc^2
$$

### Поширені математичні символи

| Символ                  | LaTeX                   | Опис                      |
| ----------------------- | ----------------------- | ------------------------- |
| $\pi$                   | `\pi`                   | Число пі                  |
| $\sum$                  | `\sum`                  | Сума                      |
| $\int$                  | `\int`                  | Інтеграл                  |
| $\sqrt{x}$              | `\sqrt{x}`              | Квадратний корінь         |
| $\frac{a}{b}$           | `\frac{a}{b}`           | Дріб                      |
| $\pm$                   | `\pm`                   | Плюс-мінус                |
| $\infty$                | `\infty`                | Нескінченність            |
| $\alpha, \beta, \gamma$ | `\alpha, \beta, \gamma` | Грецькі літери            |
| $\leq, \geq$            | `\leq, \geq`            | Менше/більше або дорівнює |
| $\neq$                  | `\neq`                  | Не дорівнює               |

### Приклади математичних формул

```mdx
### Розклад квадратного тричлена

$$
x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

### Сума арифметичної прогресії

$$
S_n = \frac{a_1 + a_n}{2} \cdot n = \frac{2a_1 + d(n-1)}{2} \cdot n
$$

### Теорема Піфагора

Для прямокутного трикутника з катетами $a$, $b$ і гіпотенузою $c$:

$$
a^2 + b^2 = c^2
$$
```

Використовуйте зворотні лапки `` `...` ``:


**Результат:** Функція `console.log()` виводить текст у консоль.

## Повний приклад статті

```mdx
---
title: 'Позиційна система числення'
description: 'Класи та розряди натуральних чисел'
difficulty: 'easy'
math: true
---

# Позиційна система числення

## Вступ

Сьогодні ми сприймаємо числа як належне. Але система, якою ми користуємося, — це один із найвидатніших винаходів людства.

## Основні поняття

### Натуральні числа

**Натуральні числа** — це числа, які ми використовуємо при лічбі: 1, 2, 3, 4, 5...

_Важливо:_ Нуль (0) зазвичай не вважається натуральним числом.

### Позиційна система

<Image
  src='https://i.imgur.com/place-value.jpg'
  alt='Розряди числа'
  width='512'
  height='384'
/>

У позиційній системі значення цифри залежить від її позиції:

- **Одиниці** — перший розряд
- **Десятки** — другий розряд
- **Сотні** — третій розряд

## Математичний запис

Число 333 у розгорнутому вигляді:

$$
333 = 3 \cdot 100 + 3 \cdot 10 + 3 \cdot 1 = 3 \cdot 10^2 + 3 \cdot 10^1 + 3 \cdot 10^0
$$

## Приклад

> **Задача:** Розкласти число 542 на розрядні доданки.
>
> **Розв'язок:**
>
> $$542 = 5 \cdot 100 + 4 \cdot 10 + 2 \cdot 1$$

## Висновки

1. Позиційна система — основа сучасної математики
2. Розряди групуються в класи по три
3. Розуміння системи числення важливо для подальшого навчання

---

_Стаття підготовлена для навчальної платформи_
```

## Корисні поради

### 1. Правильна структура

- Використовуйте заголовки H2 для основних розділів
- Розбивайте довгі абзаци на коротші (3-5 речень)
- Використовуйте списки для перерахувань

### 2. Зображення

- Завжди додавайте описовий `alt` текст
- Використовуйте `<Image>` з великої літери (не `<img>`)
- Використовуйте тільки підтримувані хостинги: **Imgur** або **imgBB**
- Завжди вказуйте `width` та `height` для контролю розміру
- Використовуйте `wrap="true"` для зображень з обтіканням тексту
- Вимкніть `shadow="false"` для прозорих PNG

### 3. Математика

- Увімкніть `math: true` у frontmatter
- Перевіряйте формули перед публікацією
- Використовуйте блокові формули для складних виразів

### 4. Українська мова

- Використовуйте лапки-ялинки: «текст»
- Дотримуйтесь правил пунктуації української мови
- Перевіряйте текст на наявність помилок
